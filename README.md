# MasasOutliner 公式操作マニュアル

ようこそ **MasasOutliner** の公式ユーザー操作マニュアルへ。

MasasOutliner は、思考の整理・長文執筆・情報集約をシームレスに行うために設計された、デスクトップ向けの本格的な階層型思考プロセッサ（アウトライナー）です。

![メイン画面](images/screen_main_layout.png)

---

## 4つのコア特長

1. **完全ローカル完結**
   * すべてのツリー構造、テキスト本文、埋め込まれた画像・音声・表計算・添付ファイル・作図アセットは1つの `.olt` ファイル内に完全完結。外部サーバーを一切介さないため、機密情報を安全にローカル管理できます。
2. **柔軟なマルチドキュメント・ドッキング＆フローティング環境**
   * タブ切り替えはもちろん、ドキュメント同士の上下・左右ドッキング分割、自由なウィンドウ分離（フローティング）に標準対応。
3. **思考を止めないハイブリッド編集**
   * 編集時以外は装飾記号が自動隠蔽されるマークダウン記法、幾何学的テーブル自動整形、Excel関数・セル結合・書式対応の内蔵スプレッドシート、LaTeX数式、高精細作図連携（UML / Mermaid / draw.io / SVG）が1つの文章内に同居します。
4. **業務文書を支える堅牢なデータ保護**
   * ネットワーク共有ドライブでの同時上書きを防ぐハイブリッド排他ロック機構、自動クラッシュリカバリ、上書き前の世代バックアップ（`.bak`）を配備しています。

## クイック操作早見表

| ショートカット | 機能 |
| :--- | :--- |
| `Ctrl + N` | 新規ドキュメントの作成 |
| `Ctrl + O` | ドキュメントを開く |
| `Ctrl + S` | 上書き保存 |
| `Ctrl + Shift + S` | 名前を付けて保存 |
| `Ctrl + P` | 印刷ダイアログの表示 |
| `Ctrl + Z` / `Ctrl + Y` | 元に戻す / やり直し（本文・ツリー操作共通） |
| `Ctrl + F` / `Ctrl + H` | 検索ツールバー / 置換ツールバーの表示 |
| `Ctrl + Shift + F` | マークダウン表の幾何学的自動整形 |
| `Ctrl + A` | 本文の全選択 |
| `Alt + ←` / `Alt + →` | 過去に選択したノードへ戻る / 進む |
| `Alt + S` | 検索時、現在のノードをスキップして次ノードへジャンプ |
| `F2` | 選択ノードのインライン名前変更 |
| `F1` | オンライン操作マニュアル（Web）を開く |
| `Ctrl + マウスホイール` | 本文内の画像・図面・表の表示倍率拡大/縮小 |
